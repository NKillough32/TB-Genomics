Step 11 - Epidemiology Reference Records

    
Optional reference library for shared epidemiology entities. Use this when the same exposure type, contact, or location may be reused across investigations. To attach evidence to a case, use Step 6.

    

      

        What this does
        Creates reusable records that can support structured epidemiology evidence.
      

      

        What it does not do
        It does not link records to a case or cluster; those links are recorded in the Cluster Investigation Centre.
      

    

    

      

        How to attach an exposure, contact, or location to a case
        Go to Step 6, load clusters, open a cluster, choose the Epi notes tab, select a case, then record a location event or contact link.
